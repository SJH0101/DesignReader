# DesignReader

영어 원서를 지면 그대로 보면서 옆에 한국어 번역을 붙여 읽는 macOS 앱.
모르는 대목을 끌면 그 자리에서 물어볼 수 있고, 메모는 그 문장에 선으로 붙는다.

번역과 해설은 **Claude Code CLI** 또는 **Codex CLI** 를 거친다. 각자 쓰던
구독 계정으로 도는 것이라 API 요금이 따로 붙지 않는다.

> 교재는 들어 있지 않다. 앱을 열고 자기 PDF 를 넣으면 그때 처리된다.

## 무엇을 하나

- **지면 + 번역 나란히** — 원본 PDF 를 그대로 띄우고 문장 단위로 짝지은 번역을 옆에 붙인다.
- **양방향 대응** — 번역을 끌면 지면의 그 자리가 켜지고, 지면을 끌면 그 대목의 번역이 켜진다.
- **스캔본 처리** — 글자가 없는 PDF 는 macOS Vision 으로 읽는다. 가로로 펼쳐 스캔한 두 쪽짜리 지면도 책등을 찾아 갈라낸다.
- **분야별 번역** — 문서를 넣으면 분야를 스스로 가려내고 그에 맞는 용어집과 말투를 쓴다.
- **메모** — 끌어놓은 대목에 메모가 붙는다. 여러 개를 동시에 펼쳐도 각자 자기 문장에 선으로 이어져 있다.
- **찾기** — 원문에서 찾은 것과 번역에서 찾은 것을 갈라 보여주고, 누르면 그 낱말 자리로 간다.

## 쓰려면

1. [DMG 를 받아](../../releases) 앱을 `응용 프로그램`에 끌어다 놓는다.
2. 처음 열면 "손상되었다"는 창이 뜬다. 서명하지 않은 앱이라 그렇다.
   시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 → **확인 없이 열기**.
3. 앱을 열고 **연결하기** 를 누른다. 설치는 앱이 다 하고, 브라우저에서
   Claude 나 ChatGPT 계정으로 한 번 로그인하면 끝이다. 터미널은 쓰지 않는다.

GPT 쪽은 ChatGPT 무료 계정으로도 되지만 한도가 빨리 찬다. 많이 번역할
생각이면 Plus·Pro 가 낫다.

Apple 실리콘(M1 이후) 전용이다.

## 직접 빌드하려면

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
bash packaging/build.sh
```

`packaging/DesignReader.dmg` 가 나온다.

## 만들면서 정한 것들

**호출 고정비를 깎았다.** 번역·해설에는 도구가 필요 없다. Claude CLI 에서
도구를 전부 끄고 기본 시스템 프롬프트를 통째로 갈아끼우면 호출당
43,629 토큰이 6,758 토큰이 된다. 문단마다 따로 부르지 않고 묶어 보내는데,
너무 크게 묶으면 응답이 잘려 통째로 실패하므로 실패하면 반으로 쪼개
다시 시도한다.

**용어를 강제할 것과 맡길 것으로 나눴다.** `field` `agency` `artifact` 처럼
분야가 바뀌면 뜻이 통째로 달라지는 단어를 "반드시 이렇게 옮겨라"로 묶으면,
의학 논문의 imaging artifact 가 '인공물'이 된다. 뜻이 하나뿐인 용어만
강제하고 나머지는 후보만 알려준다.

**글자를 건드리지 않는다.** 표시는 전부 좌표 위에 상자를 덧그리는 방식이다.
본문을 감싸 고치면 선택 영역과 검색 위치가 어긋난다.

**문서 번호를 다시 쓰지 않는다.** 지면 이미지 주소가 번호로 정해지는데,
지운 번호를 물려주면 브라우저가 이전 문서의 지면을 캐시에서 내놓는다.

**빌드가 화면 깨짐을 잡는다.** 규칙이 사라져 화면이 서식 없이 흘러버린 일이
여러 번 있었다. `check_js.py` 는 사라진 함수를, `check_css.py` 는 규칙 없는
class 를 빌드 전에 잡는다.

## 구조

```
app/
  main.py        앱 진입점 — 서버를 띄우고 창을 연다
  server.py      HTTP API
  extract.py     PDF → 문단 (단 나누기, 머리말 제거, 하이픈 복원)
  ocr.py         스캔본 — Vision 으로 읽기, 펼침면 가르기
  translate.py   묶음 번역, 실패하면 쪼개서 재시도
  prompts.py     분야별 용어집과 프롬프트
  ai.py          Claude / Codex CLI 연결
  setup.py       CLI 설치와 로그인
  db.py          SQLite
  static/        화면
packaging/
  build.sh       .app 빌드 → 서명 → DMG
  check_js.py    사라진 함수 검사
  check_css.py   규칙 없는 class 검사
```

번역은 원문 글자의 해시로 묶여 있어서, 문서를 지웠다 다시 넣어도 그대로
살아난다. 저장 자리는 `~/Library/Application Support/DesignReader/` 이고
앱을 지워도 남는다.

## 안 담는 것

교재 PDF 와 거기서 뽑아낸 원문·번역·지면 이미지는 저장소에 넣지 않는다.
저작권이 있는 남의 글이다. `.gitignore` 가 막고 있다.
